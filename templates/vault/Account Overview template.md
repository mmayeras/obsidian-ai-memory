# Account Overview template

Reusable reference for a customer account, kept separate from `Cases/` and `Meetings/`. Lives at
`Customers/<Name>/Info/Account Overview.md`. Files for the account (contracts, decks, org charts,
roster screenshots, etc.) live alongside it in the same `Info/` folder, no separate attachments
subfolder. Filled in by the `customer-onboard` skill/command — see
`templates/cursor/skills/customer-onboard/SKILL.md`.
